# 참고 자료 출처

`data/layouts.json`과 `data/ux.json`은 Next Level Builder의 UI/UX Pro Max 자료 일부를 발췌한 것입니다. 원본은 MIT 라이선스로 제공되며 저작권·허가 문구를 `LICENSE`에 보존했습니다.

- 저장소: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- 원본 버전: 2.15.0
- 고정 커밋: `ccce51cba388476d4f403091ddb91636d5cd9fed`
- 원본 URL, 수집 시각, 필드와 행 선택, 원본 텍스트 SHA-256: `data/provenance.json`

레이아웃 자료에는 패턴 식별자·이름·검색어·섹션 순서·주 행동 위치만 포함합니다. UX 자료는 22개 항목의 문제와 권고를 담습니다. 색상, 서체, 스타일 프리셋, 효과, 간격 수치, 운영 모션 정책, 코드 예제와 디자인 시스템 생성 코드는 포함하지 않습니다.

검색기는 DDS용으로 별도 작성했습니다. 결과는 검토할 참고 자료이며 화면 생성·최적화 결과가 아닙니다. 사용자 요구사항, 현재 서비스 기능, 등록된 DDS 규칙을 우선합니다.
